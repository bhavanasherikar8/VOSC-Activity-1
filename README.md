\# 🎮 Tic Tac Toe



A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.



\## 📌 About the Project



This project is a two-player Tic Tac Toe game where players take turns placing X and O on a 3×3 game board.



The game automatically detects:

\- 🏆 Winner

\- 🤝 Draw

\- 🔄 Player turns



\## ✨ Features



\- Two-player gameplay

\- 3×3 game board

\- Automatic winner detection

\- Draw detection

\- Restart game button

\- Player turn indicator

\- Simple and responsive user interface

\- Hover effects on game cells



\## 🛠️ Technologies Used



\- HTML

\- CSS

\- JavaScript



\## 🎮 How to Play



1\. Open `index.html` in a web browser.

2\. Player X starts the game.

3\. Players take turns clicking an empty cell.

4\. The first player to get three marks in a row wins.

5\. If all cells are filled without a winner, the game ends in a draw.

6\. Click \*\*Restart Game\*\* to start a new game.
